# TaskManager
A simple task organization website, written in React JS and using Supabase for authentication and storage.
WARNING: Data entry is not currently encrypted. Until implemented, please note that all data entered (except for passwords) is visible to database administrators.
Hosted at: https://taskmanager.chirpsoft.workers.dev/
# Features
Simple drag-and-drop interface
Fast load times (React SPA)
RLS for data security
